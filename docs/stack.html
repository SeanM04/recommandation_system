Development environment

  • Python 3.11 or newer. Developed on 3.12; pyproject.toml declares >=3.11.
  • Editable install. make install installs the pinned requirements and the recommender package with pip install -e ., so scripts and tests import the same code.
  • Virtual environment outside OneDrive. On Windows, OneDrive locks files inside a project .venv and pip fails with WinError 32. Create it elsewhere, for example %USERPROFILE%\.venvs\telco-recommender, and select it as the editor's interpreter.
  • Make on Windows. make is the documented interface, but every target is one plain command. Without it, run the command from the Makefile directly, or install it with winget install ezwinports.make.
  • Database. Postgres 18 with the Telco_Dynamic_Recomender database. Copy .env.example to .env and fill in DB_PASSWORD (and the other DB_* values if they differ); without them the project uses a local SQLite file. Tests use a throwaway pytest_recommender schema and never touch the real tables.
  • Line endings. .gitattributes keeps LF line endings in the repository so the Makefile and Docker files behave the same on every platform.
